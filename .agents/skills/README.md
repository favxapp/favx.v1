# Skills do projeto

Procedimentos específicos da FAVX. Caminhos citados são relativos à raiz do repositório.

| Skill | Quando usar |
|---|---|
| [favx-requirements](favx-requirements/SKILL.md) | Interpretar documentos, delimitar incrementos e registrar decisões |
| [favx-ui](favx-ui/SKILL.md) | Alterar telas, componentes, tokens e idiomas |
| [favx-supabase](favx-supabase/SKILL.md) | Alterar Auth, banco, políticas e migrations |
| [favx-vercel](favx-vercel/SKILL.md) | Configurar ambientes e verificar deployments |

Complementam `AGENTS.md` sem ampliar a autorização da tarefa. Para adicionar uma skill, criar pasta com `SKILL.md`, frontmatter com nome/descrição, fontes, procedimento e validação. Revisar scripts externos antes de executá-los.
